# Customer Segmentation using KMeans Clustering

## Overview

This project focuses on customer segmentation using machine learning. It groups customers based on their behavior using the KMeans clustering algorithm. The goal is to identify different types of customers and understand their patterns for better decision-making.

---

## Objective

The main objective of this project is to:

- Analyze customer behavior  
- Group similar customers together  
- Help businesses make data-driven decisions such as targeting and retention strategies  

---

## Machine Learning Model

**Algorithm:** KMeans Clustering  
**Type:** Unsupervised Learning  
**Features used:** Recency, Frequency, Monetary (RFM)

The model automatically identifies patterns in the data and assigns each customer to a specific cluster based on similarity in behavior.

---

## Key Insights

- Customers are divided into distinct groups based on spending behavior  
- High-value and low-value customers can be easily identified  
- Helps in understanding customer engagement levels  
- Supports targeted marketing and retention strategies  

---

## Workflow

- Data preprocessing  
- Feature selection (RFM analysis)  
- Data scaling  
- Finding optimal clusters using the Elbow Method  
- Applying KMeans clustering  
- Analyzing customer groups
